================================================================================
NOTES ON FORMULAS
================================================================================

Key Formula Components:
- $C$4 = Season Start Date (absolute reference - won't change when copied)
- (ROW()-9)*7 = Days to add (each row = 1 week = 7 days)
- ISOWEEKNUM() = ISO week number (1-53)
- WEEKDAY(..., 2) = Returns 1-7 where Monday=1, Sunday=7

If formulas don't work:
1. Check that C4 contains a valid date
2. Copy the formula cells individually and paste to other rows
3. Change ROW()-9 to ROW()-[actual row where data starts]

Example: If your data starts at row 12 instead of row 9:
Change (ROW()-9)*7 to (ROW()-12)*7
