PROGRAM AKTIV - QUICK REFERENCE CARD
========================================

FOR A NEW SEASON: 5 SIMPLE STEPS

Step 1: Enter Season Details
  - Go to INPUT SECTION (top of sheet)
  - C3: Enter season name (e.g., "2025-2026")
  - C4: Enter start date (e.g., "2025-09-01")

Step 2: Week Numbers Auto-Calculate
  - All week columns auto-calculate based on start date
  - No manual date entry needed!

Step 3: Verify Schedule Structure
  Use the pre-configured matchup table:
  ┌────────────────────────────────┐
  │ 10 Regular Rounds (2 matches)   │
  │ 3-4 FRI ODDS Rounds (money only)│
  │ Each team plays all others 2x   │
  └────────────────────────────────┘

Step 4: (Optional) Randomize Teams
  If you want to change team matchups:
  - Edit columns E, F, G (Hold 1, Hold 2, Fri Odds)
  - Keep the structure: 10 regular + 3-4 fri odds rounds
  - Verify each team plays all others twice

Step 5: Done!
  - Print or share the schedule
  - Start entering results in notes/score columns as season progresses

FORMULAS - IF SOMETHING BREAKS
  Week Number:
    =ISOWEEKNUM($C$4+(ROW()-9)*7)

  Week Start (Monday):
    =DATE(YEAR($C$4+(ROW()-9)*7),MONTH($C$4+(ROW()-9)*7),DAY($C$4+(ROW()-9)*7)-WEEKDAY($C$4+(ROW()-9)*7,2)+1)

  Week End (Sunday):
    =[Week Start] + 6

  Adjust (ROW()-9) if data starts on different row
