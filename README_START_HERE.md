## Key Features of the New Design

### Automatic Calculations
- Week numbers compute from season start date
- Week start/end dates (Monday-Sunday) auto-calculate
- All formulas use relative references so they copy easily

### Fair Schedule
- 10 regular rounds (2 matches per round)
- 3-4 "fri odds only" rounds (all teams get money, no matches)
- Each team plays every other team exactly 2 times
- No team plays same opponent twice in a row

### Clean Layout
- Input section at top (season name + start date)
- Clear schedule with headers
- Room for notes/scores in each row
- Color-coded fri odds rounds
- Optimized for printing

### Easy to Maintain
- Next season: just copy the sheet and update dates
- Randomize: if desired, edit team columns but keep structure
- Backup: old seasons stay in separate sheets
